# MGU five apps 0.2.0

Графический выпуск: все пять приложений переписаны с текстовых экранов на
canvas-приборные панели в стиле OEM (kit/runtime, GPU 60 fps через renderd,
PNG-fallback ~10 fps).

## Что нового

- **marku_x3_health 0.1.0 → 0.2.0** — вкладки Обзор/История/Отчёт: плитка
  аккумулятора с трассой истории, таблица CBS с цветными статусами, плитка
  ECU с покрытием, график 12 В по снимкам, отчёт об изменениях от базовой линии.
- **marku_x3_warm 0.1.0 → 0.2.0** — радиальные приборы масла и ОЖ, кольцо
  готовности, расчёт оставшихся минут, климат-рекомендация с уровнем, вкладка
  истории прогревов с графиком.
- **marku_daily_hud 0.1.0 → 0.2.0** — живое превью карточки отклонения,
  статусы контура cluster-render, панель текущих отклонений 12 В/шин/CBS,
  включение слоя кнопкой на экране и в bar.
- **marku_x3_home 0.1.0 → 0.2.0** — большие кнопки сцен «Возвращаюсь»/
  «Выезжаю» (подтверждение двойным нажатием), снимок автомобиля с перечнем
  отправляемых полей, журнал действий, статус bridge.
- **marku_x3_trips 0.1.0 → 0.2.0** — вкладки Сейчас/Итоги/Журнал: приборы
  текущей поездки, полоса топлива, плитки итогов периода, график километров
  по дням, таблица поездок с категориями.
- **marku-home-bridge 0.1.0** — без изменений.

## Инфраструктура

- `SKILL.md` — стандарт разработки MGU-приложений (canvas-first, виджеты kit,
  интерактив, безопасность, сборка/публикация).
- `docs/top5-graphical-apps-analysis.md` — разбор реализации топ-5 графических
  приложений upstream (M Vitals, eDrive, G-Force, Redline, Drag Timer).
- `tools/preview-apps.js` — хост-превью: рендерит все экраны в PNG
  (`dist/preview/`) без автомобиля.

## Границы (без изменений)

Read-only по отношению к ECU: ни одно приложение не выполняет запись в блоки,
не очищает DTC/CBS и не обещает remote start. HUD включается только вручную
после проверки на автомобиле. Bridge не содержит токен: pairing выполняет
владелец.

## Проверка выпуска

- `npm test` — логика моделей, загрузка собранных пакетов в head-unit stub,
  целостность каталога и запрет write-вызовов.
- `node tools/preview-apps.js` — PNG всех экранов.
- Экраны на автомобиле не испытывались; PNG-fallback и GPU-путь проверены
  только хост-рендером.
