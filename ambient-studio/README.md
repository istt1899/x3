# Студия света для BMW iDrive

Русский форк Ambient Config 2.7.17 для MGU Store. Информация о версии и установочный пакет доступны на [странице выпуска](https://github.com/istt1899/x3/releases/tag/ambient-studio-1.0.0).

## Установка и первый тест

1. На стоянке откройте MGU Store, подключите магазин к интернету и выберите **Settings → Check now**. Источник этого приложения — **istt1899/x3**, канал **Releases**.
2. Откройте **Студия света → Install**. Магазин укажет необходимые зависимости. Если он показывает **Restart pending**, выберите **Settings → Restart head unit**.
3. В меню приложений BMW откройте **Студия света → Свет → Фары и эффекты**. Переключите кадр, укажите левую или правую фару и измените время. Сценарий сохраняется как **Свой**. Фары отображаются на экране.
4. Для проверки салона верните подсветку под управление BMW в исходном Ambient Config, если вы им пользовались. В студии откройте **Свет → Салон**, выберите **Янтарь** и посмотрите, какие зоны изменились. Кнопка **Штатный свет** возвращает управление автомобилю. Результат зависит от установленных модулей подсветки.
5. В разделе **Проверка** проверяются модель салона, расчёт цвета и кадры сценария. Это программная самопроверка. Физический свет проверяется наблюдением на машине.

Форк устанавливается отдельной плиткой с идентификатором `marku_ambient_studio`. Первый выпуск запускается вручную. Его можно удалить в **MGU Store → Installed → Студия света → Remove**. Упакованы интерфейсы ID7 и ID8. Испытания этого выпуска на реальном автомобиле пока не проводились.

## Сборка и проверка

Из каталога `ambient-studio`:

```sh
python3 kit/tools/build.py --store --language ru marku_ambient_studio
node kit/tools/test_ambient_config.js
node kit/tools/test_ambient_rgb.js
node kit/tools/test_ambient_studio.js
```

Пакет `dist/marku_ambient_studio@1.0.0.tgz` содержит RHMI-ресурсы и приложение. При установке MGU Deploy подключает SDK головного устройства. Пакет воспроизводится побайтово при повторной сборке из тех же исходников.

Исходное приложение и App Kit — [cauliflowermossgrape/idrive7-apps](https://github.com/cauliflowermossgrape/idrive7-apps/tree/e2716cdd8d779141262a078fe192cade6cf26f4b). Русский словарь исходного проекта подготовил Иван (Fieldistor). Лицензия приложения находится в [LICENSE](LICENSE).
