# Студия света для BMW iDrive

Русский форк Ambient Config для MGU Store. Информация о версии и установочный пакет доступны на [странице выпуска](https://github.com/istt1899/x3/releases/tag/catalog).

## Установка и первый тест

1. На стоянке откройте MGU Store, подключите магазин к интернету и выберите **Settings → Check now**. Источник этого приложения — **istt1899/x3**, канал **Releases**.
2. Откройте **Студия света → Update** или **Install**. Магазин укажет необходимые зависимости. Если он показывает **Restart pending**, выберите **Settings → Restart head unit**.
3. Откройте **Студия света → Свет → Фары и эффекты → Стробоскоп**. Для первого запуска выберите **Вместе** и оставьте **Дальний свет**. Кнопка **Предпросмотр** проигрывает выбранный эффект на экране с замедлением в четыре раза.
4. На закрытой площадке, при **0 км/ч** и положении селектора **P**, нажмите **Запустить фары → Подтвердить запуск**. Доступны одновременные вспышки и серии. Для режима **По очереди** нужен кузовной блок с раздельным управлением обеими фарами. При поддержке временных команд можно выбрать **Дальний / ПТФ**, которые вспыхнут по очереди. **Световое шоу** доступно в предпросмотре. Фары можно остановить с той же кнопки, цикл занимает около 8 секунд. Реакцию фар подтвердите наблюдением.
5. Для работы со своей сценой нажмите **К редактору кадров**, выберите кадр и настройте фары и длительность. **Тест кадров** проиграет сцену на изображении BMW.
6. Если вы пользовались исходным Ambient Config, сначала верните в нём управление подсветкой автомобилю. В студии выберите **Салон → Янтарь** и посмотрите, поменялся ли цвет подсветки в машине. **Цвет и яркость** открывает точную настройку. **Штатный свет** возвращает обычный режим BMW. Реакция салона зависит от оборудования автомобиля и активного режима движения.
7. Откройте **Проверка → Запустить проверку**. Приложение проверит модель салона, расчёт цвета и данные кадров. Изменение света в машине подтверждается наблюдением на месте.

Форк устанавливается отдельной плиткой с идентификатором `marku_ambient_studio` и запускается вручную. Для удаления откройте **MGU Store → Installed → Студия света → Remove**. В пакет входят интерфейсы ID7 и ID8. Проверка этого выпуска на автомобиле пока предстоит.

Версия 1.0.4 устанавливается поверх 1.0.3. В положении P достаточно одного уведомления селектора и свежих данных скорости. При выходе со страницы, потере подтверждения стоянки или изменении скорости приложение завершает цикл и возвращает управление BMW. Команды временных вспышек и выбор кузовного блока основаны на [Ambient Config 2.8.4](https://github.com/cauliflowermossgrape/idrive7-apps/blob/23e128fc4c92d7803ba6daf32ef7c543de31a1d7/apps/ambient_config/strobe.js).

## Сборка и проверка

Запустите из каталога `ambient-studio`.

```sh
python3 kit/tools/build.py --store --language ru marku_ambient_studio
node kit/tools/test_ambient_config.js
node kit/tools/test_ambient_rgb.js
node kit/tools/test_ambient_studio.js
```

Проверка студии проходит через нативный экран, касание и контроллер iDrive. Чтобы сохранить кадры дисплеев 1920×720 и 2880×960, выполните `node kit/tools/test_ambient_native_ui.js /tmp/ambient-screens` на компьютере для сборки.

Пакет `dist/marku_ambient_studio@1.0.4.tgz` содержит RHMI-ресурсы и приложение. При установке MGU Deploy подключает SDK головного устройства. Пакет воспроизводится побайтово при повторной сборке из тех же исходников.

Исходное приложение и App Kit — [cauliflowermossgrape/idrive7-apps](https://github.com/cauliflowermossgrape/idrive7-apps/tree/e2716cdd8d779141262a078fe192cade6cf26f4b). Русский словарь исходного проекта подготовил Иван (Fieldistor). Лицензия приложения находится в [LICENSE](LICENSE).
