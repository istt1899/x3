# Студия света для BMW iDrive

Русский форк Ambient Config 2.7.17 для MGU Store. Информация о версии и установочный пакет доступны на [странице выпуска](https://github.com/istt1899/x3/releases/tag/ambient-studio-1.0.1).

## Установка и первый тест

1. На стоянке откройте MGU Store, подключите магазин к интернету и выберите **Settings → Check now**. Источник этого приложения — **istt1899/x3**, канал **Releases**.
2. Откройте **Студия света → Install**. Магазин укажет необходимые зависимости. Если он показывает **Restart pending**, выберите **Settings → Restart head unit**.
3. В меню приложений BMW откройте **Студия света**. Сразу откроется **Свет → Фары и эффекты**. Выберите **По очереди**, затем один из четырёх кадров. Кнопки **Левая фара**, **Правая фара** и кнопка времени меняют выбранный кадр. Свой вариант сохранится на устройстве. **Проверить длительность** запускает маркер на шкале времени. Схема фар меняется при выборе кадра вручную. Наружные фары автомобиля в этом испытании не включаются.
4. Если вы пользовались исходным Ambient Config, сначала верните в нём управление подсветкой автомобилю. В студии выберите **Салон → Янтарь** и посмотрите, поменялся ли цвет подсветки в машине. **Цвет и яркость** открывает точную настройку. **Штатный свет** возвращает обычный режим BMW. Реакция салона зависит от оборудования автомобиля и активного режима движения.
5. Откройте **Проверка → Запустить проверку**. Приложение проверит модель салона, расчёт цвета и данные кадров. Изменение света в машине подтверждается наблюдением на месте.

Форк устанавливается отдельной плиткой с идентификатором `marku_ambient_studio` и запускается вручную. Для удаления откройте **MGU Store → Installed → Студия света → Remove**. В пакет входят интерфейсы ID7 и ID8. Проверка этого выпуска на автомобиле пока предстоит.

## Сборка и проверка

Запустите из каталога `ambient-studio`.

```sh
python3 kit/tools/build.py --store --language ru marku_ambient_studio
node kit/tools/test_ambient_config.js
node kit/tools/test_ambient_rgb.js
node kit/tools/test_ambient_studio.js
```

Проверка студии проходит через нативный экран, касание и контроллер iDrive. Чтобы сохранить кадры дисплеев 1920×720 и 2880×960, выполните `node kit/tools/test_ambient_native_ui.js /tmp/ambient-screens` на компьютере для сборки.

Пакет `dist/marku_ambient_studio@1.0.1.tgz` содержит RHMI-ресурсы и приложение. При установке MGU Deploy подключает SDK головного устройства. Пакет воспроизводится побайтово при повторной сборке из тех же исходников.

Исходное приложение и App Kit — [cauliflowermossgrape/idrive7-apps](https://github.com/cauliflowermossgrape/idrive7-apps/tree/e2716cdd8d779141262a078fe192cade6cf26f4b). Русский словарь исходного проекта подготовил Иван (Fieldistor). Лицензия приложения находится в [LICENSE](LICENSE).
