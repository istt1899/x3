# ТЗ: «Видео в движении» для VK Видео и RUTUBE (MGU)

- Дата: 08.11.2026. Статус: **Готово к реализации** (решения приняты владельцем и советом COUNCIL-RU.md; вопросов нет).
- Объект: `istt1899/x3`, main @ c019396; общий UI `media/ui/main.js` для приложений VK Видео и RUTUBE.
- Пользователь: владелец автомобиля (пассажиры/кодированная под видео-в-движении машина), на свой риск — как в RideTube.

## 1. Цель и результат

Сейчас: у VK/RuTube видео жёстко отключено при движении (`noVideo = parked.moving()`, переключателя нет); у YouTube-приложения переключатель есть. Три приложения ведут себя по-разному (дефект согласованности, находка аудита №1).

Ожидаемо: в настройках VK Видео и RUTUBE появляется «Видео в движении» (выкл по умолчанию). Включение действует, только если выполнено на стоянке со свежей скоростью; в движении переключатель ничего не включает; выключение на ходу гасит картинку сразу. Приборка (cluster) видео в движении не получает никогда. Звук и контролы в движении сохраняются (подкаст-режим при выключенном видео).

## 2. Объём

Входит: общий гейт в `media/ui/main.js`; настройка в `media/tools/build_apps.py` (фильтр + русская метка); версии приложений 0.1.7; обновление ассертов сборки/релиза; новые тесты защёлки; тексты DESIGN.md и доков; публикация релиза `media-preview-0.4.5-r3` и обоих каталогов.

## 5. Краевые случаи

- Нет скорости / устаревшая скорость при НЕармленной защёлке → видео скрыто (fail-closed).
- Перезапуск приложения на ходу → защёлка сброшена (память процесса), fail-closed.
- Выключение на ходу — подхват циклом sync() ≤250 мс (без settings.onChange, как у YouTube).
- Смена целевого экрана на cluster в движении → картинка уходит из приборки всегда.
- Сторонний код не должен мочь армить гейт: настройка только через штатный экран настроек HMI.

## 6. Предположения и ограничения

- Совет принял: устаревшая скорость при армленой защёлке не гасит видео (как RideTube) — зафиксировано AC-006 как контракт; риск принят владельцем.
- HMI-рендер новой настройки проверен только hu-stub; живая приёмка — AC-011.
- Строки 33 языков: одна таблица копируется во все локали генератором; русская метка видна на всех языках (как у прочих настроек VK/RuTube) — принято советом.
- Юридическая оговорка в метке и релиз-нотах сохраняется: только пассажиры, на свой риск.
