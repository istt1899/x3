# Кодировки X3 для MGU Store

Отдельные приложения **VK Видео** и **RUTUBE**, а также общий проигрыватель с
RideTube находятся в [`media/`](media/README.md).
**[Как установить видеоприложения через MGU Store](media/INSTALL-STORE-RU.md).**
Первый выпуск обозначен тестовым: личный вход и воспроизведение проверяет владелец
на своём MGU.

Версия 0.1.2: пакет приложения для BMW X3 G01 с MGU/iDrive 7. Реализованы каталог десяти функций и ограниченное диагностическое обнаружение ECU. **Запись кодировок отсутствует.** Установка, интерфейс и чтение на целевой машине пока не проверены.

Короткий адрес источника для ввода в MGU Store: **`istt1899/x3`** (тип GitHub Releases). Полная ссылка: https://github.com/istt1899/x3.

Исходники и сборка кодировок лежат в `mgu-coder/`. Для повторной сборки требуются Node.js 18+ и команды `npm run build`, `npm test` из этой папки. В GitHub Releases размещены архив приложения `marku_x3_coding@0.1.2.tgz` и общий релиз `catalog` для MGU Store. При публикации нужно сохранять остальные компоненты общего каталога; coding-only publisher защищён от их случайного удаления.

Диагностику запускают только на стоянке. Приложение не проверяет скорость самостоятельно; штатный `Speedlockable` ещё требует проверки на MGU.

Пакет не содержит данные BimmerCode, BMW SDK, VIN или архивы автомобиля. Ограничения по совместимости и условия перехода к реальному кодированию описаны в техническом задании.
