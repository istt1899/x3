# Кодировки • X3 для MGU Store

Версия 0.1.0: устанавливаемое приложение для BMW X3 G01 с MGU/iDrive 7. Показывает каталог десяти востребованных функций и по запросу выполняет ограниченное диагностическое обнаружение ECU. **Запись кодировок отсутствует.** Работа на целевой машине пока не проверена.

Короткий адрес источника для ввода в MGU Store: **`istt1899/x3`** (тип GitHub Releases). Полная ссылка: https://github.com/istt1899/x3.

- [Возможности и установка](mgu-coder/README.md)
- [Техническое задание](mgu-coder/SPEC.md)
- [Исследование BimmerCode, форумов и MGU](mgu-coder/RESEARCH.md)
- [Инструкция независимому аудитору](mgu-coder/AUDIT-PROMPT.md)
- [Готовый USB-каталог](output/x3-coding-usb/mgu-repo/x3-coding)

Исходники и сборка лежат в `mgu-coder/`. Для повторной сборки требуются Node.js 18+ и команды `npm run build`, `npm test` из этой папки. В GitHub Releases размещены архив приложения `marku_x3_coding@0.1.0.tgz` и релиз `catalog` для MGU Store.

Пакет не содержит данные BimmerCode, BMW SDK, VIN или архивы автомобиля. Ограничения по совместимости и условия перехода к реальному кодированию описаны в техническом задании.
