# Совет по Атласу 0.13.0

Разбор исходника на коммите f4cf3586ce4f58a7b98b75973f1878ead18c184a.

| Роль | Вывод | Решение |
| --- | --- | --- |
| Интерфейс iDrive и графический тракт | В режиме «Картограф» редактор рисовал условную карточку и редактировал дисплеи по очереди. Нативный сервис уже умел выводить предупреждение в оба физических слоя. | Использовать сцену поездки на центральном экране и растр нативной карточки для каждого физического слоя. Общий размер передавать одним запросом. Сохранять отдельные позиции, яркость, прозрачность и состав. |
| Открытые источники и дорожная геометрия | Конвертер московского слоя терял URL, временную отметку и условные лимиты. Соседство камеры с дорогой или совпадение координат нескольких баз не подтверждает дорогу, поток и знак. | Восстановить исходные поля и привязывать подход только при совпадении узла камеры и дороги. Справочный лимит карты отображать с источником. |
| Приёмка и риски | Независимые экраны подтверждают слои по отдельности. Общий номер изменения можно проверить цифровым тестом. Графические слои нельзя приравнять к физически измеренной оптике. | Проверить цифровые растр и геометрию, отзыв теста при движении, атомарное сохранение и независимую доступность выходов. Физическую приёмку вести по записи с автомобиля. |

На повторной независимой проверке совет уточнил условия: отбрасывать примыкания с несколькими дорогами, учитывать параллельные проезды при сопоставлении в движении, скрывать значение с карты сразу при потере уверенного подхода и не извлекать из направления объектива сторону съёмки. Сохраняется невытесняющий режим слоя, поэтому проверка музыки на HUD включена в программу приёмки.
