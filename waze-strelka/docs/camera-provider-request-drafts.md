# Запрос поставщику данных — подготовленный текст

Это заготовка для рассмотрения владельцем проекта. Сообщения поставщикам не отправлялись.

## RadarBase / Airbits

Здравствуйте! Разрабатываем общественное приложение предупреждений о камерах для BMW MGU / iDrive 7. Нужен региональный набор для города Калуги и Калужской области (RU-KLU), пригодный для локальной работы без постоянного интернета.

Просим сообщить условия API или регулярного feed, стоимость и права на серверное получение, кэширование на автомобиле, нормализацию формата и обновления. Базовый проект публичный. Нужны либо явные права на распространение регионального набора вместе с приложением, либо разрешённая модель отдельной пользовательской авторизации без публикации закрытых данных на GitHub.

Какие поля доступны: стабильный идентификатор устройства и отдельно направления/рубежа, координаты с оценкой точности, адрес, модель комплекса, виды контроля, применимый числовой лимит и происхождение лимита, направление движения контролируемого потока, сторона фиксации, статус работы, дата проверки, временные ограничения и удалённые записи? Просим определить семантику каждого направления, происхождение данных и различие стационарных, передвижных, временных и муляжных объектов.

Также нужны: контрольная региональная выборка для оценки покрытия, описание версии и дельт, интервалы обновлений, правила удаления/устаревания, атрибуция и ограничения отображения на приборной панели/HUD. Поддерживаемая среда автомобиля — Linux/Node.js 8; Android/iOS SDK сам по себе не обеспечивает эту совместимость.

## Speedcamonline / региональный куратор

Используется тот же запрос с акцентом на согласованную выгрузку RU-KLU, права на нормализованный публичный региональный набор и документирование формата: запись-направление против физического устройства, курс автомобиля, способ обозначения неизвестного лимита, достоверность типа, временные средства, муляжи и удаления. Совпадение с источниками RD-forum нужно обозначить как общее семейство, а не независимое подтверждение.

## Mapcam / Radarbot

Нужна отдельная договорная интеграция. Обычная подписка на приложение не рассматривается как разрешение на извлечение и перераспространение базы. Для Radarbot дополнительно требуется подтвердить доступность региона и пригодность партнёрского интерфейса для MGU; для Mapcam — согласованный способ получения данных без автоматического извлечения вопреки правилам проекта.
