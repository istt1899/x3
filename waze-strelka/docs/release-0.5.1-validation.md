# Waze Стрелка 0.5.1: исправление лимита «Рядом»

Сценарий владельца: Суворова/Плеханова, карточка «Рядом», около 70 м до рубежа, текущая скорость 19 км/ч, BMW показывает 60, карточка показывает вопросительный знак.

Причина: guidance сохранял собственный лимит OSM как cameraLimitKmh, но обнулял эффективный limitKmh до подтверждения подъезда. Renderer читал только эффективный лимит. Дополнительно при выборе официальной записи исходный лимит действительно отсутствовал, хотя ранее рассмотренные связанные OSM-записи имели согласующееся 60.

Исправление:

- Renderer отдельно показывает подтверждённый лимит дороги и известный справочный лимит базы.
- Справочное число выделено янтарным контуром, подписью «Рядом • база»; дорожное подтверждение не имитируется.
- Для официальной записи допустима отдельная справка из ранее рассмотренных связей рубежа. Прямые официальные данные не переписываются, совпадение по радиусу не используется, конфликт приводит к неизвестному значению.
- Неизвестное значение отображается тире. Общего городского 60 по умолчанию нет.
- Сигнал превышения по справочному значению не включается; чтение BMW Speed Limit Information в патче не реализовано.
- Источник, ID и числовые значения доступны на всех блоках страницы «Камера» и в снимке диагностики.

Повторная проверка первоисточника 07.11.2026: OSM API для 11980400006, 12157150894, 12157150895 и 13340703428 вернул maxspeed=60 для всех четырёх. Эти значения уже были в опубликованной базе. Пример: https://www.openstreetmap.org/node/11980400006 .

Проверки: полный npm test; весь native-набор на Node 8.17; отдельный реальный daemon → display adapter/public state → frozen diagnostics; сценарий 70 м с полной базой 308 записей; все четыре OSM-объекта и официальный рубеж; отсутствие ссылки, конфликт 40/60, неизвестное значение, приоритет подтверждённого ограничения; SHA опубликованной базы неизменен; upstream-валидаторы пакетов; побайтовая воспроизводимость LF/CRLF. Карточка отрисована реальным renderer-кодом и осмотрена на компьютере.

База остаётся 2026.11.7.1. Новый автомобильный тест не проводился. Обновляются приложение и сервис до 0.5.1.
