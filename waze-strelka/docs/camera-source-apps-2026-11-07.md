# Совет по источникам камер: Android/iPhone приложения

Проверено 7 ноября 2026 г. Исследование публичных первоисточников, без доступа к аккаунтам, платным выгрузкам, APK-декомпиляции или автомобилю. «Хат» из запроса, вероятно, означает HUD Speed; это предположение, а не установленное точное название приложения.

## Вывод для проекта BMW

Самый полезный результат — не ещё один список приложений, а разделение исходных семейств данных. **HUD Speed и GPS Антирадар используют RadarBase. Стрелка/eStrelka используют пересекающийся сборник Speedcamonline/RD-forum и других источников.** Совпадение точек в нескольких таких приложениях не является независимым подтверждением. Лицензия на использование приложения не равна разрешению встроить и распространять его базу в публичном форке.

Для публичного JSON/репозитория рекомендую сейчас использовать только источники с установленными условиями распространения: уже существующую OSM-ветку и собственные проверяемые наблюдения, плюс официальные данные после проверки конкретных условий. Для RadarBase, Speedcamonline, Mapcam и Radarbot — отдельные адаптеры с выключенным распространением до получения подходящей лицензии/согласования. Публичные карты полезны для выявления пробелов и последующей проверки по первичным сведениям, но не дают автоматически права сделать bulk-копию.

## 1. Стрелка / eStrelka: Android и iOS

**Факт.** Официальное руководство eStrelka называет основной сборник: RD-forum, Speedcam.online, POIplaza, раздел навигации 4PDA и проверенные/отфильтрованные пользовательские точки. Описывает ручное скачивание, ежедневную автоматизацию и импорт текстового iGo-файла. FREE и PRO выбирают разные варианты базы. Интернет нужен для загрузки; предупреждения работают локально. Это опубликованная документация, а не проверка текущего бинарного приложения. [Официальная загрузка eStrelka](https://www.ivolk.ru/a163.htm).

**iPhone.** Официальная страница Стрелки также подтверждает сборник источников, импорт файлов/прямых ссылок и пользовательские точки. Описывает тип объекта, расстояние, скорость и лимит; фоновые предупреждения имеют ограничения iOS. [Стрелка для iPhone/iPad](https://www.ivolk.ru/istrelka.htm).

**Доступ для нас.** Импорт iGo в клиент подтверждён; публичный стабильный API экспорта полной базы, SLA и лицензия на её повторную публикацию на GitHub не установлены. Названия формата iGo недостаточно для декодирования vendor-specific числовых типов: нужен конкретный профиль формата с примерами, направлением и версией. Покупка PRO сама по себе не доказывает право перераспространения.

## 2. HUD Speed / GPS Антирадар / RadarBase

**Факт о происхождении.** Разработчик Airbits прямо указывает RadarBase.info источником данных и для HUD Speed, и для GPS Антирадара. Это одно семейство данных, а не два независимых доказательства. На странице есть официальные ссылки на магазины Android/iOS и карту RadarBase. [Airbits, разделы HUD Speed и GPS Антирадар](https://airbits.ru/).

**Обновления.** Официальная promo-страница HUD Speed заявляет почасовое обновление базы, проверку модераторами, хранение базы на устройстве и локальную работу. Это заявление разработчика, не проверенная нами текущая частота публикаций или SLA. Старые promo и магазинные описания могут говорить о разных частотах сервера и FREE-клиента; их нельзя превращать в единое гарантированное расписание. [Официальная promo-страница](https://airbits.ru/hud_speed/promo.htm).

**Поля и геометрия.** Отдельная официальная страница различает стационарную камеру, полосу, обочину, красный/стоп-линию, контроль сзади, парную среднюю скорость и вероятные места мобильных установок. Также описывает виртуальную точку предупреждения на стоп-линии: координата записи не всегда координата устройства. [Типы предупреждений HUD Speed](https://airbits.ru/hud_speed/alerts.htm).

**Важное ограничение доказательств.** Поисковый индекс официальной темы RadarBase «Типы объектов», версия 2.10 от 20.11.2025, указывает: луч — зона предупреждения навстречу потоку, пунктирный хвост — дополнительный контроль сзади. Прямое открытие сайта показывает только SPA-заглушку старого браузера; полный текущий текст через JS не проверялся. [Тема RadarBase](https://radarbase.info/forum/topic/7-Tipi_obektov_v_baze_RadarBase.info).

**Доступ для нас.** Документированный открытый bulk-export/API и разрешение распространять базу в публичном проекте не найдены. Не следует реконструировать частные мобильные endpoints или извлекать платный кэш вместо лицензионного подключения. Вариант — согласование регионального data feed у оператора; запрос пока не отправлялся.

## 3. MapcamDroid / Mapcam Info

**Как работает сообщество.** Официальная iOS-инструкция описывает встроенную и обновляемую базу, авторизацию, подписку/тип базы, автообновление и отправку пользовательских объектов с подтверждением через сайт. У записей есть рейтинг; отрицательные/нулевые записи не означают автоматически действующую камеру. Документ содержит старые примеры iOS, поэтому конкретные актуальные тарифы и UI из него не выводим. [Инструкция Mapcam Info](https://mapcam.info/api/v4i/help/ru/index.php).

**Условия.** Правила проекта §9 требуют согласования для распространения базы или её части, а также для коммерческого использования. §1.8 запрещает ботов. Обязательная ссылка на Mapcam не отменяет отдельное ограничение распространения. [Правила Mapcam.info](https://mapcam.info/help/agreement.php?language=russian-utf8).

**Экспорт.** Официальный форум отдельно сообщает, что полная база не выгружается для сторонних программ, а актуальная база доступна в официальных приложениях. Это исключает трактовку подписки как разрешения сделать публичный JSON для BMW. [Обсуждение выгрузки для стороннего устройства](https://mapcam.info/forum/index.php?language=russian-utf8&topic=6171.0), [проблемы выгрузки](https://mapcam.info/forum/index.php?topic=4131.0).

**Для нас.** Только отдельное согласованное партнёрство; не массовый сбор карты/обход авторизации. Никакие данные Mapcam в репозиторий этим исследованием не добавлялись.

## 4. Speedcamonline / RD-forum

Это не одно и то же юридическое/техническое лицо. RD-forum даёт канал кураторов и исходных наблюдений, а Speedcamonline — самостоятельную базу/экспорты. Старые форумные описания экспорта нельзя выдавать за текущую открытость всех данных.

**Условия сайта.** Индексируемые страницы Speedcamonline содержат обязательную атрибуцию и условие согласования коммерческого использования. Это не найденная открытая лицензия на произвольное перераспространение всей базы. [Пример страницы с условиями](https://speedcamonline.ru/map/Rus/1333/).

**Доступность.** Прямой HTTPS-запрос к корню Speedcamonline во время проверки вернул 503; региональный маршрут также не открылся через web-инструмент. Это результат текущего доступа, не доказательство закрытия сервиса. Индекс показывает записи региона RU/40, в том числе модели, адреса, курсы, лимиты и автора изменения; это не полная актуальная региональная выгрузка и не основание импортировать обрывки из выдачи.

**Самый важный контракт.** В актуальной шапке RD-forum указано: курс — азимут движения автомобиля, а не направление взгляда камеры; одна запись — отдельное направление контроля, не обязательно физическое устройство. Контроль сзади может быть отдельной записью. Административная сводка страницы датирована 22.10.2026, исходная шапка — последней редакцией 23.10.2026. [Правила исправления точек у кураторов](https://www.rd-forum.ru/threads/izmenenie-suschestvujuschix-tochek-speedcamonline-ru.6046/page-56).

**Для нас.** Перспективный источник после согласования экспорта региона и условий распространения. Сохранять ID направления отдельно от device ID, автора/источник и дату изменения. Нельзя дедуплицировать направления простым совпадением координат.

## 5. ContraCam

Официальное магазинное описание заявляет автоматическую загрузку базы, ежедневную модерацию, офлайн-режим и сопровождение нескольких объектов. Экспорт GPX/KML/CSV указан среди возможностей коллекций меток и треков; из текста нельзя заключить, что разрешён экспорт и перераспространение всей базы камер. Конкретный внешний поставщик camera feed в рассмотренной странице не назван. [Описание iOS от разработчика](https://apps.apple.com/ru/app/%D0%B0%D0%BD%D1%82%D0%B8%D1%80%D0%B0%D0%B4%D0%B0%D1%80-contracam-%D0%BF%D0%BE%D1%81%D1%82%D1%8B-%D0%B4%D0%BF%D1%81/id1150201048).

Официальное Android-описание подтверждает регулярное автообновление, категории стационарных радаров и опасностей. Публичные API и права на включение базы в BMW не установлены. [Android ContraCam 4](https://play.google.com/store/apps/details?hl=ru&id=com.mybedy.antiradar).

Публичный канал производителя описывал более компактный целочисленный формат обновлений и отправку коррекций офлайн с последующей доставкой. Это полезный пример архитектуры, а не опубликованный формат/API для стороннего использования. [Канал ContraCam](https://t.me/s/contracam_news?before=101).

## 6. Radarbot

Официальный help center говорит об обновлении с помощью сообщества, поставщиков и серверов ежедневно, но прямо перечисляет причины отсутствующих камер и возможные задержки. Ни одна такая база не доказывает стопроцентное покрытие. [Почему камер может не быть](https://help.radarbot.com/en/articles/13926708-why-there-are-missing-cameras-radars-on-maps).

Есть реальное предложение **SDK для разработчиков**, включая embedded/connected-vehicle сценарии. Указаны Android, iOS и Web; доступ ограничен партнёрами. Публичные документация протокола, региональный SLA/прайс и совместимость с Node 8 BMW MGU не опубликованы в рассмотренной странице. [Radarbot для разработчиков](https://www.radarbot.com/desarrolladores/).

Условия от 04.02.2026 §12 прямо ограничивают извлечение, повторное использование и воспроизведение базы вне приложения. Поэтому SDK — кандидат на отдельное соглашение, а не разрешение извлечь базу из обычной подписки. [Условия Radarbot](https://www.radarbot.com/terminos-y-condiciones-de-uso/).

## Что требуется от любого согласованного feed для Калужской области

### Кому имеет смысл запросить условия

1. **RadarBase/Airbits** — первый кандидат для предметного разговора о региональном feed: один оператор ведёт данные, карту и два российских приложения с нужными категориями. Запросить точный RU-KLU охват, разрешение обновляемого runtime-кэша и, отдельно, право публичного распространения снимков. Пока это рекомендация по выбору партнёра, не измерение качества его калужской базы.
2. **Speedcamonline** — параллельный кандидат с существующей сетью российских кураторов и явным контрактом направлений. Сначала выяснить доступность, формат, региональный SLA и права. Текущий 503 не позволяет обещать устойчивый feed.
3. **Mapcam** — обращаться только за специальным партнёрским разрешением; обычную подписку не считать лицензией интеграции. Ограничения сторонних выгрузок делают этот путь менее прямым.
4. **Radarbot** — наиболее явно опубликованный SDK-путь, но прежде закупки потребовать sample RU-KLU, качество направления/лимитов и способ офлайн-обновления на Linux/Node 8. Android/iOS SDK не являются нативным SDK BMW MGU; Web SDK также нуждается в отдельной проверке совместимости.

Авторам ничего не отправлялось. Для первого письма достаточно попросить не всю российскую базу, а согласованный региональный sample, схему, права и условия обновления; цену и полноту заранее не обещать.

Это рекомендации совета, а не утверждение, что перечисленные сервисы уже предоставляют эти поля:

- Территория RU-KLU и **географический полигон региона**, включая внешние подступы к границе. Нельзя считать любой строковый адрес «Калуга» доказательством положения внутри области.
- Разделять физический комплекс, сенсор, направление/полосу контроля, предупреждающую виртуальную точку и участок средней скорости. Идентичные координаты не равны дубликату.
- Хранить `approachBearing`, `cameraFacingBearing` и `captureSide` как разные поля. Значение «в спину» брать из явного подтверждённого атрибута, а не выводить только из одного азимута.
- Контроли (`speed`, `redlight`, `stopline`, `lane`, `belt`, `phone`…) и модель комплекса — разные сущности. Технические возможности модели не доказывают включённые на данном месте виды фиксации.
- Для лимита нужны значение, полоса/направление, дата и источник. Неизвестное остаётся неизвестным; не подставлять 60 автоматически только по городу.
- Нужны события удаления/демонтажа и изменения направления, а не только добавления. Отдельно кодировать муляж, неработающий комплекс, историческое место мобильной установки и актуальное временное сообщение с TTL.
- Вести `sourceFamily`, `sourceRecordId`, `sourceRevision`, `retrievedAt`, `verifiedAt`, ссылку/основание и статус прав на распространение для каждого поля. Согласие нескольких приложений одного семейства не увеличивает независимую уверенность.
- Обновлять серверный региональный snapshot отдельно от релиза приложения: инкрементальный сбор при наличии официального feed, периодический полный resync, локальная модерация спорных изменений, проверка схемы/хэша и атомарный last-good rollback. Частоту публикации выставлять по реально доступным источникам, а не рекламному обещанию.

## Границы исследования

Прямой Яндекс-поиск запрошен по теме «Стрелка HUD Speed откуда база камер». Web-инструмент не открыл SERP; обычный HTTPS-запрос вернул SmartCaptcha. Капча не решалась и не обходилась. Дальнейший поиск выполнен веб-поиском с переходом к первоисточникам. Нельзя описывать результат как полный просмотр всего Рунета или как доказанно полную базу всех камер области.

Приложения не устанавливались, сетевые протоколы закрытых клиентов не перехватывались, с правообладателями не связывались. Исследование устанавливает опубликованные источники и ограничения, а не текущее внутреннее устройство каждой версии приложения. Число актуальных физических камер по области здесь не вычислялось.
