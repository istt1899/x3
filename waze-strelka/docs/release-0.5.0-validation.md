# Проверка Waze Стрелка 0.5.0

Проверено 07.11.2026 на компьютере. Автомобиль не подключался; физическая видимость HUD/приборов и реальные подъезды этим отчётом не подтверждаются.

- Полный `npm test`: успешно, включая native/IPC, интерфейс, восстановление GPS, watchdog, калибровку, 11 490 проверок локализации и проверки новых источников.
- Все native-проверки, экран приложения, GPS bridge/lifecycle и локализация на официальном Node 8.17: успешно.
- `node tools/build.js` и `node tools/test_packages.js`: успешно; оба upstream-валидатора, SHA/размеры и регистрация сетевого UID 5000 проверены.
- `npm run test:repro`: архивы приложения и сервиса побайтово одинаковы для LF/CRLF.
- Импорт XLSX: 8 проверок; source refresh: 19 автономных проверок. Реальный HTTPS source refresh получил официальный файл и полный PBF; хеш официального файла прежний, нормализованные camera-факты OSM не изменились.
- База: 308 записей источников, включая 152 официальные позиции; 19 прежних дорожных коридоров сохранены. Три географических исключения не попадают в runtime; 184 парковочных маршрута не объявляются стационарными камерами.
- Повреждённый/пропавший официальный каталог или quality policy сохраняет старую базу под правильной старой версией и оставляет причину в диагностике. Сохранённая полная база не заменяется частичной. Явная проверка обновлений восстанавливает полную базу.
- Обновление 156 → 308 из пакета работает без сети, сохраняет предыдущую базу. Явный откат переживает перезапуск, не подавляет будущий пакет и снимается после успешной проверки нового канала.
- Неверные officialCount/provider counts, возвращённые quarantined ID и подмена контекста источника отклоняются валидатором.
- Симуляции известных подъездов проверяют виды контроля и контекст рубежа; неизвестные лимит, модель и сторона фиксации не подставляются. Это проверка данных/протокола, не реального срабатывания в автомобиле.

Канал данных v2 отделён от прежнего manifest. Рекомендуемый следующий автомобильный тест: обновить оба компонента до 0.5.0, проверить версию базы и происхождение данных, затем на стоянке проверить геометрию сохранённых профилей и тест изображения. Реальные подъезды и точность дорожного сопоставления проверяются отдельно.
