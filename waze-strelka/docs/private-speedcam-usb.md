# Личное обновление «Пульс» для BMW iDrive 7

## Установка 0.10.1

Распакуйте папку **mgu-repo** из личного ZIP в корень флешки. На ней должен получиться путь **mgu-repo/kaluga-cameras/catalog.json**. В стоящей машине откройте **Store → USB** и установите оба компонента из этого каталога. Если Store предлагает установку по одному компоненту, сначала выберите сервис, затем приложение «Яндекс Стрелка».

Для обновления на автомобиле требуются установленные общие компоненты Store: waze-on-cluster версии 0.9.14 или выше, mgu-deploy версии 0.7.11 или выше и cluster-render версии 0.4.0 или выше. В диагностике после запуска должны отобразиться приложение 0.10.1, сервис 0.10.1 и связь ОК. Состояние дополнительной базы проверяется в разделе регионов. После установки дополнительный слой доступен без интернета.

## Сборка из исходников

Нужны Python 3, Node.js и подготовленный личный файл speedcam-private.json. Оба аргумента пути ниже должны находиться за пределами репозитория каталога. Выходной ZIP должен быть новым файлом.

```sh
python3 tools/build_private_usb.py /path/to/private/speedcam-private.json /path/to/private/Strelka-Pulse-0.10.1-USB.zip --version 0.10.1
```

Сборщик запускает штатный генератор MGU Store и валидаторы приложения и сервиса в отдельной временной папке. Он сверяет встроенный файл с исходными байтами и проверяет SHA-256 пакетов внутри итогового ZIP. Публичная сборка по-прежнему формируется командой `node tools/build.js`.

По результатам сверки релизов [idrive-apps](https://github.com/robertnisipeanu/idrive-apps/releases) для сборки 0.10.1 текущие опубликованные версии Maps on cluster 0.6.12, waze-on-cluster 0.13.0 и cluster-render 0.8.0 совпали с проверенными для 0.10.0.
