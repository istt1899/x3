# Москва и Московская область — источники и правила релевантности (0.9.0)

| Источник | Записи | Примечание |
|---|---|---|
| OSM Калужская область (база) | 150 + 5 relation | без изменений, road-зоны привязаны к её PBF |
| ГИБДД Калуга | 152 | без изменений |
| Сообщения владельца | 1 | без изменений |
| OSM Московская область (вкл. город) | 1 366 | снимок `moscow_oblast.osm.pbf` от 2026-11-17, MD5 `0a503217c6e6f7cadd10756c1b6b377e` |

Итого 14 200 записей (~8,8 МБ бандл). Каждая community-запись несёт поле
`region`: `RU-KLU` | `RU-MOW` (город) | `RU-MOS` (область).

## Правила релевантности

1. **Только стационарное контрольное оборудование** — те же шесть типов, что и
   для Калуги: `static_cam`, `speed_cam`, `control_cam_red`, `video_control`,
   `dummy` (муляжи водителям релевантны), `stationary_porst_dps`. Мобильные
   засады и «типовые места» по политике источника исключены и учтены в аудите.
2. **География по атрибуции точки**, не по прямоугольнику: прямоугольник
   33.2–40.6 / 53.3–57.3 только ограничивает выборку; принимаются точки с
   регионом «Москва», «Московская область», «МО», «Калужская область».
   Соседние регионы (Тула, Рязань, Тверь, Владимир, Ярославль) — в аудите
   исключений, в базу не попадают.
3. **Дедупликация**: OSC-точка в ≤60 м от существующей записи не добавляется
   (`nearExistingRecord`); внутри OSC — 15 м между точками. Повторное слияние
   OSM-снимка идемпотентно.
4. **Рейтинг сообщества**: в выборке по Москве нет точек с рейтингом ≤ −3,
   порог не понадобился; все спорные точки (рейтинг < 0) сохраняются — как и
   в Калуге, спор сообщества не повод молчать о камере.
5. **Честность типов**: муляжи помечены «Муляж камеры» в описании; лимиты —
   только заявленные источником (OSM `maxspeed`, OSC `speed`); без
   «городских 60 по умолчанию».

## Чего нет и почему

- **ГИБДД по Москве/МО**: официальный сайт (гибдд.рф) отдаёт 403 с этой
  сети (WAF). Перечень Калуги был получен 2026-11-07 до ограничения. Добавим
  при первом доступном скачивании — отдельной версией базы, с тем же
  контрактом региона.
- **Road-зоны для Москвы**: 19 зон привязаны к калужскому PBF. Москва работает
  через режим «рядом» (0.8.6): движение + сектор 40° + направление; OSM-точки
  Москвы несут `rawDirection`, OSC — азимут потока. Зоны для московских дорог —
  отдельная большая работа (построение коридоров по московскому PBF).

## Производные данные

Поля `capture` не сохраняются в бандл — они выводятся при загрузке
(`capture-data`), чтобы опубликованная база оставалась фактами источников.
Лимиты транспорта подняты осознанно: бандл 8→16 МБ, инспекция записей
350k→1.5M узлов — с комментариями в коде.
