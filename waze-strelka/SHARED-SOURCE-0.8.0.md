# Выпуск 0.8.0 в общем источнике x3

Владелец уточнил09.11.2026: в автомобиле добавлен **istt1899/x3**, тип GitHub Releases. Публикация0.8.0 в отдельном репозитории камер не обновляла этот источник. Предыдущее утверждение, что отдельный репозиторий уже был источником автомобиля, было неверным.

В общий каталог переносятся оба проверенных пакета0.8.0, значок и резервный USB ZIP. Их байты, версии, ID/UUID, настройки и база не меняются. Изменяются место публикации и host-документация; восемь остальных компонентов сохраняются полностью, включая зависимости, URL и SHA. IMPORT.json содержит происхождение и точные контрольные суммы.

Корневой catalog.json — единственный общий каталог для Store. Вложенный каталог описывает только камеру и её общие зависимости. Старый standalone prepare заблокирован; правила публикации записаны в AGENTS.md. Все дальнейшие новые публикации выполняются только в istt1899/x3.

Старый встроенный read-only адрес базы0.8.0 пока не переносился: смена его owner-bound проверки потребует отдельного совместимого runtime выпуска. Это явно отделено от исправленного источника Store. Новый выпуск в прежний репозиторий этим переносом не публикуется.

Локальная проверка общего каталога: tools/verify_waze_strelka.py. Внешняя проверка должна подтвердить каталог релиза, main/catalog.json и оба пакета через настоящий reader/fetch MGU Updater0.8.18, источник istt1899/x3. Аппаратная установка и работа на X6M не подтверждены.
