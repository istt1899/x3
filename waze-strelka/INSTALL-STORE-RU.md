# Waze Стрелка в MGU Store

Единственный источник новых обновлений: **`istt1899/x3`**, тип **GitHub Releases**. Новую ссылку добавлять не нужно.

Выпуск0.8.0: **Waze Стрелка** и **Waze Strelka camera service**. В Store откройте **Настройки → Проверить**, затем обновите приложение и сервис. При запросе Store выполните перезапуск. На стоянке откройте **Камеры → Диагностика**, при блокировке после прежней неверной даты выполните явный сброс истории GPS и выберите страницу GPS.

Компактное меню, независимые HUD/приборы и исправление блокировки кнопок описаны в [README](README.md). Работа на конкретном X6M ещё не подтверждена. База2026.11.7.2 и недоступность реального звука не изменены. Встроенный read-only адрес обновления базы0.8.0 пока остаётся прежним; это не источник Store и не разрешение публиковать туда новые выпуски. Перенос этого адреса потребует отдельного совместимого runtime обновления.

Все новые публикации выполняются только в x3. Общий корневой catalog.json сохраняет Bimmer Code, RideTube, VK, RUTUBE и общие зависимости без изменений. Вложенный catalog.json служит только описанием камер; им нельзя заменять общий каталог. Legacy standalone prepare заблокирован.

Проверки из waze-strelka/: npm ci --ignore-scripts; npm run build; npm test; npm run test:packages. Из корня: python tools/verify_waze_strelka.py; python tools/verify_waze_strelka.py --public. IMPORT.json сохраняет происхождение и хэши. Пакеты0.8.0 побайтно совпадают с проверенной сборкой; смена источника Store не меняет их идентификаторы и настройки.
