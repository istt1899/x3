# Установка «Яндекс Стрелка · Атлас» на BMW iDrive 7

## Через Store

1. На стоящей машине откройте **Store → Настройки**, выберите источник GitHub Releases **istt1899/x3** и запустите проверку обновлений.
2. В разделе **Установленные** обновите «Яндекс Стрелка» и «Сервис камер Атлас». Старая плитка может называться «Waze Стрелка». Прежние идентификаторы приложения и сервиса позволяют обновиться поверх установленной версии.
3. После завершения откройте приложение и его **Диагностику → Снимок для фото**. В первой строке должны быть приложение **0.11.2**, сервис **0.11.2** и связь **ОК**. Для проверки вывода откройте настройки HUD или приборов и запустите тест на стоянке при свежем измерении нулевой скорости.

4. Откройте **Базы и регионы** и проверьте строку **SpeedCamOnLine**. После первой успешной загрузки появится **«загружен • 2026-11-01»**. Сервис хранит данные в машине и повторяет загрузку при восстановлении сети.

## Резервная установка 0.11.2 через USB

Скачайте на компьютер [Strelka-Atlas-0.11.2-USB.zip](https://github.com/istt1899/x3/releases/download/waze-strelka-0.11.2/Strelka-Atlas-0.11.2-USB.zip). Распакуйте папку **mgu-repo** в корень флешки. В машине откройте **Store → USB**, выберите приложение и сервис и выполните установку. Архив содержит оба обновляемых компонента. На MGU должны быть установлены общие зависимости из каталога Store, в том числе waze-on-cluster 0.9.14 или новее, mgu-deploy 0.7.11 или новее и cluster-render 0.4.0 или новее.

## Камеры и ограничения

База из комплекта работает без интернета. На экране регионов можно выбрать пакет, проверить доступную версию, скачать обновление и вернуться к предыдущей версии. При прерывании связи текущая база остаётся активной. После возвращения связи выберите тот же пакет и возобновите загрузку.

При предупреждении центральный дисплей, HUD и приборы показывают лимит для подтверждённого подхода. Пометка «КАРТА» означает справочное значение по конкретному участку дороги и направлению движения. Оно само по себе не включает сигнал превышения. Когда у базы есть только точка камеры, поле выглядит как «Лимит —». В карточке камеры видны направление, идентификатор и основание лимита. При разборе проблемы достаточно снимка диагностики, сделанного на стоянке.
