# Waze Стрелка в общем источнике MGU Store

**Waze Стрелка 0.7.0** и **Waze Strelka camera service 0.7.0** опубликованы
в общем источнике **`istt1899/x3`**, рядом с RideTube, VK Видео и RUTUBE.

1. В MGU Store откройте **Настройки → Проверить**.
2. На вкладке **Store** выберите **Waze Стрелка** и нажмите **Установить**
   или **Обновить**. Магазин подберёт сервис камер, Waze on cluster и renderer.
3. При запросе перезапуска используйте **Настройки → Перезапуск**.

Если общего источника ещё нет, добавьте **`istt1899/x3`**, тип **Релизы**,
затем повторите проверку. Полный HTTPS-адрес того же каталога:
`https://raw.githubusercontent.com/istt1899/x3/main/catalog.json`.

Прежние идентификаторы `marku_kaluga_cameras` и `marku-kaluga-cameras`
сохранены. Если уже установлена 0.7.0, повторное обновление этой же версии
не требуется. Установленный компонент может сохранять прежний источник:
если Store не предлагает обновление более старой версии, сохраните показанные
версию, источник и текст ошибки. Удалять приложение и его настройки для
переноса в общий каталог не требуется.

Версия приложения при переносе не менялась. База остаётся 2026.11.7.2;
её существующее обновление использует прежний канал данных
`istt1899/bmw-kaluga-cameras`. Перенос репозитория не меняет базу и настройки.
Звуковой адаптер BMW в 0.7.0 ещё недоступен. Проверка на компьютере
не подтверждает видимость новых предупреждений и звук на конкретном MGU.

## Исходники и проверка

Из папки `waze-strelka/`:

```sh
npm ci --ignore-scripts
npm run build
npm test
npm run test:packages
```

Из корня общего репозитория:

```sh
python tools/verify_waze_strelka.py
python tools/verify_waze_strelka.py --public
```

Общий `catalog.json` в корне — каталог публикации. Вложенные `catalog.json`,
`store-downloads.json` и инструменты прежнего издателя сохранены как часть
исходного выпуска; они относятся к отдельному репозиторию камер. Не заменяйте
ими общий каталог. При следующем выпуске объединяйте записи компонентов,
сохраняя остальные приложения и обновляя контрольную сумму общего каталога
в `media/RELEASE-EVIDENCE.json`.

Папка `packages/` содержит точные опубликованные архивы, значок и USB-копию.
Адреса в общем каталоге закреплены на неизменяемом коммите этого репозитория.
