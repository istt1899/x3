# План и запись интеграции 0.8.0

Основание: [готовое ТЗ](compact-camera-menu-0.8.0.md), REQ-001–015, AC-001–008. Требования и четыре уточнения критика приняты до продуктовых изменений; этот файл фиксирует границы выполненных задач и оставшуюся проверку интеграции.

| Задача | Граница | Проверка | Состояние |
|---|---|---|---|
| UI и навигация | Шесть native дочерних разделов; registry ресурсов; отдельные профили; подтверждённые результаты; debounce/tail/hold после rollback | Actual-handler compact navigation; полный прежний UI; граф XML/JSON; Node8/24 | PASS |
| Диагностика времени | Полный BMW RMC UTC, wall сервиса, signed receipt delta, cutoff; без ослабления допуска GPS | Реальный JSONL/decoder/provider/service; старый cutoff; reset; устаревание теста | Реализовано, локально проверено Node8/24 |
| Сохранность обновления | Настройки 0.7 без записей при открытии; независимость профилей; Done; процессный restart; EROFS | Реальный файл настроек и дочерние процессы сервиса | Проверено Node8/24 |
| Обзор реализации | Независимый ограниченный review по AC после реализации; авторский тест не заменяет review | Diff, handlers, lifecycle, реальные ограничения | PASS, FR-01 закрыт повторной probe |
| Интеграция и выпуск | Версии0.8, прежние ID/UUID/источник; неизменная база; канонические байты архивов | Полный npm test, Node8, build, валидаторы, LF/CRLF, публичное скачивание SHA/size | PASS; оба релиза и прежние каталоги опубликованы, оба reader/fetch источника и Actions42604700956 прошли |
| Проверка владельцем | Стоянка; GPS/UTC; реальная видимость HUD/приборов; iDrive Back/focus; выход из теста | X6M с корректной датой и новой диагностикой | Не выполнена: ноутбук не подключён |

Публикация разрешена владельцем в текущей цепочке запросов; новый источник или установка на неподключённый автомобиль в задачи не входят. При повторном отказе на машине нельзя выдавать локальное воспроизведение за установленную причину её текущего состояния.
