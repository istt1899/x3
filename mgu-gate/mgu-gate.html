Автоворота

Подъезжаете к воротам с любой стороны — на 20 метрах до них приложение само отправляет команду открытия. Команда идёт по вашему проверенному механизму (Яндекс IoT, инструкция в архиве MarkInfo). Ничего лишнего: одна страница, без сети, без внешних библиотек.

Вы уже внутри зоны ворот. Автооткрытие не сработает, пока вы не выедете за её пределы и не подъедете снова — это защита от случайных повторов.
Браузер может блокировать ответ Яндекса (CORS). Если команда уходит, а ворота не открываются, переключите в настройках режим на «Свой webhook» (например через OpenClaw) — внешний ответ там не нужен.

Токен даёт управление вашим умным домом. Он отправляется только выбранному API ворот и хранится в профиле этого браузера (localStorage): его может прочитать любая страница, открытая в этом же браузере. Не открывайте чужие страницы в профиле MGU с введённым токеном; при компрометации отзовите токен в Яндексе. Ответ Яндекса браузер может не показать (CORS) — если статуса нет, а ворота открылись, всё в порядке; для гарантированного подтверждения используйте «Свой webhook».

Стрелка · уведомление при подъезде

При приближении к воротам «Стрелка» покажет карточку «Ворота — 20 м». Уведомление работает независимо от автооткрытия.

URL приёма алертов «Стрелки» (её локальный HTTP-приёмник)

Приёмник ждёт POST с JSON {event:"gate_approach"|"gate_trigger"|"test", dist, auto}. Добавьте в «Стрелку» обработчик этого адреса — тогда её карточка будет всплывать, как по камерам. Автооткрытие у ворот включается и выключается верхним переключателем «Автоматическое открытие».

Симуляция подъезда

Проверьте всю цепочку за столом: виртуальная машина поедет к воротам, приложение сработает как вживую.

Если что-то пошло не так

Коды ответа и действия
  • 401 — проверьте токен и один пробел после Bearer.
  • 403 — проверьте право iot:control у токена.
  • ERROR / DEVICE_UNREACHABLE — Яндекс не подтвердил действие. Сохраните ответ, автоматические повторы не добавляйте.
  • Тайм-аут — сначала посмотрите на ворота: команда могла дойти. Повторяйте только вручную.
  • CORS-блокировка в браузере — ответ Яндекса недоступен странице. Используйте режим «Свой webhook».
Как это работает

Пока вы дальше внешнего радиуса, приложение на охране. При пересечении его приложение переходит в режим ожидания. При первом попадании в круг 20 м (точность GPS не хуже порога) отправляется одна команда открытия и начинается пауза: повтор возможен только после выезда из зоны и окончания паузы. Парковка внутри зоны при запуске приложения автокоманды не вызывает.
