# Автоворота · mgu-gate

Однофайловое приложение для BMW X3 G01 (MGU / iDrive 7): автоматическое открытие
ворот при подъезде. Страница автономна — без сети и внешних библиотек, работает
из браузера MGU или любого другого браузера.

## Как работает

- Геозона вокруг ворот: 54.506731, 36.292166. Радиус срабатывания 20 м (настраивается).
- Срабатывание по расстоянию — с любого направления, курс не нужен.
- Автопостановка на охрану за 150 м; одна команда на подъезд; пауза 120 с и повтор
  только после выезда из зоны. Старт приложения внутри зоны автокоманды не вызывает.
- Команда открытия — проверенный механизм Яндекс IoT API (инструкция владельца,
  MARKINFO:MI-4A967B68B3D3B09F1B8C): POST https://api.iot.yandex.net/v1.0/devices/actions,
  устройство РосДомофон. Альтернатива — «свой webhook» (OpenClaw и т.п.).
- Уведомление при подъезде в приложение «Стрелка»: POST на настраиваемый локальный URL
  (event: gate_approach / gate_trigger / test).
- Автооткрытие включается и выключается переключателем на главном экране; ручная
  кнопка «Открыть ворота сейчас» доступна всегда.

## Установка на MGU

1. Скопируйте `mgu-gate.html` на ГУ (или откройте с внутреннего хоста).
2. Откройте файл в браузере MGU. Параметр `?src=sim` принудительно включает симуляцию
   (проверка за столом, сухой прогон без реальной отправки).
3. В настройках введите OAuth-токен Яндекса (Bearer). Токен хранится только в
   localStorage этого браузера и не попадает в файл.

## Источник координат

- «GPS браузера MGU» — если браузер отдаёт геолокацию;
- «Локальный GPS-демон (URL)» — демон на ГУ, читающий штатный SOME/IP-канал
  позиционирования (тот же мост, что использует «Стрелка»), отвечает JSON
  `{"lat":…,"lon":…,"speed":…,"acc":…}`;
- «Симуляция» — виртуальный подъезд с выбором стороны.

## Ограничения и безопасность

- Браузер может не показать ответ Яндекса (CORS): команда уходит, но страница не
  видит подтверждения. Тогда используйте режим «Свой webhook».
- Токен даёт управление умным домом — не пересылайте файл с введённым токеном.
- Живое открытие ворот впервые проводите на стоянке вручную (кнопка) и проверьте
  глазами; автоматику включайте после первого успешного ручного открытия.
- Диагностика ответов: 401 — токен/пробел после Bearer; 403 — право iot:control;
  ERROR / DEVICE_UNREACHABLE — сохранить ответ, не повторять автоматически.
