# VK Видео и RUTUBE 0.1.8 — «Видео в движении», исправление для машин без сигнала скорости

Выпуск для установки через Store: VK Видео **0.1.8**, RUTUBE **0.1.8**. Общий сервис **0.4.5** и YouTube **0.3.16** не менялись (в релизе — те же байты, что в media-preview-0.4.5-r2). Bimmer Code 0.2.0 сохранён.

## Что исправлено в 0.1.8

На части головных устройств сигнал скорости (`Vehicle2.statusCarSpeed2`) не приходит вообще — тогда строгая защита считала машину вечно «в движении», и видео не показывалось даже на стоянке. Теперь: если владелец явно включил «Видео в движении» и сигнала скорости нет совсем, машина считается стоящей. Без включённой настройки поведение прежнее: нет сигнала — нет видео. Устаревший сигнал после движения по-прежнему считается движением.

## Что было в 0.1.7

Настройка **«Видео в движении»** в обоих приложениях (выключена по умолчанию): включение действует только со стоянки, выключение на ходу гасит картинку сразу, приборка видео в движении не получает никогда. Звук и контролы работают всегда.

Предназначено для машин, кодированных под видео в движении, и пассажиров. Вы используете это на свой риск.

## Проверки

25 штатных тестов + матрица защёлки (9 состояний) зелёные; релизный тест проверяет наличие настройки в пакете. Процесс: аудит → совет → ТЗ в `specs/video-driving-20261108/`.
