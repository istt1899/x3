# VK Видео и RUTUBE 0.1.7 — «Видео в движении»

Выпуск для установки через Store: VK Видео **0.1.7**, RUTUBE **0.1.7**. Общий сервис **0.4.5** и YouTube **0.3.16** не менялись и не перевыпускались (их байты в релизе — те же, что в media-preview-0.4.5-r2). Bimmer Code 0.2.0 сохранён.

## Что нового

В настройках обоих приложений появился пункт **«Видео в движении»** (выключен по умолчанию), тот же паттерн, что в YouTube:

- включение действует, только если переключатель был включён **на стоянке** — нажатие на ходу картинку не включает;
- выключение на ходу гасит картинку сразу;
- приборка (cluster) видео в движении не получает никогда;
- звук и контролы работают всегда; при выключенном видео в движении — подкаст-режим, как раньше.

Предназначено для машин, кодированных под видео в движении, и пассажиров. Вы используете это на свой риск.

## Проверки

- Аудит кода перед изменением: `../specs/video-driving-20261108/` (аудит, совет, ТЗ).
- Все 25 штатных тестов + новая матрица защёлки (7 состояний) зелёные; релизный тест проверяет наличие настройки в пакете.
- Релиз собран из проверенных бинарей (ytdec/yt-dlp из подтверждённого источника, FFmpeg со сверкой происхождения).

Проверка на конкретном MGU (настройка видна, арминг только на стоянке, приборка пустая в движении) — отдельный шаг владельца.
