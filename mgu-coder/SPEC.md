# ТЗ: кодирование BMW X3 G01 с экрана MGU

Статус: 07.11.2026. Версия 0.1.4 реализует каталог и диагностическое обнаружение блоков на чтение. Цель следующего этапа — проверенное изменение выбранных настроек непосредственно из приложения MGU Store на **этой X3**, с резервной копией и восстановлением. Наличие MGU Store само по себе не означает доступность записи в DME, ACSM или BDC.

## Целевая среда

- BMW X3 G01, HU_MGU, iDrive 7, MGU Store установлен и работает. Перед установкой проверить текущую версию HU, совместимость SDK donor и наличие `InternalTasu` в SOME/IP master catalog конкретной MGU.
- RHMI/OAP-приложение под Node.js 8 и штатный экран; пакет исходников Store собирает OAP на головном устройстве. Взаимодействие только через задокументированные для этого пакета интерфейсы.
- Настройки доступны по комплектации и ПО, а не по одному названию модели. Локальные FA/SVT/NCD от 02.11.2026 относятся к исходному состоянию до flash; актуальный I-Level и текущие NCD нужно прочитать заново.

## Функции v1

Это редакционный выбор по [официальному списку G01/F97 BimmerCode](https://bimmercode.app/vehicles/g01/) и обсуждениям владельцев, не статистический рейтинг. В текущем релизе реализованы **карточки и диагностика вероятного адреса ECU**. Кодирование ни одного пункта не включено.

| № | Пользовательская настройка | ECU для дальнейшей проверки | Условие |
|---|---|---|---|
| 1 | Память / отключение Auto Start Stop | DME_BAC2 | На бензиновом I-Level 23-3+ отключение игнорируется; проверить текущий I-Level. |
| 2 | SPORT INDIVIDUAL как режим при запуске | BDC_BODY2 в каталоге; BDC_BODY3 на X3 | Сверить доступные режимы и CAFD; это возможный обход ограничения №1. |
| 3 | Только начальный звук ремня после запуска | ACSM5 | Не менять визуальные предупреждения и напоминания в движении. |
| 4 | Варианты цвета контурной подсветки | BDC_BODY2 в каталоге; BDC_BODY3 на X3 | Проверить наличие подсветки и поддерживаемые цвета. |
| 5 | Складывание зеркал при комфортном закрытии | BDC_BODY2 в каталоге; BDC_BODY3 на X3 | Проверить физическое электроскладывание на машине. |
| 6 | Отключение Active Sound Design | RAM / ASD_01 | Только если штатный ASD присутствует и параметр найден. |
| 7 | Давление/температура шин на приборке | HU_MGU | FA содержит 2VB, но пригодность вывода нужно проверить. |
| 8 | Значения спорт-показателей | HU_MGU | Часть данных может отсутствовать со стороны DME. |
| 9 | Частота обновления цифровой скорости | DKOMBI4 | Для подтверждённого DKOMBI4 проверить значения 2/5/10 Гц. |
| 10 | Максимальная громкость при запуске | HU_MGU | Настройка HU_MGU, 10–50% по каталогу G01. |

Официальные карточки G01 для режима запуска, подсветки и зеркал указывают **BDC_BODY2**. В сохранённом SVT этой X3 находится **BDC_BODY3**. Совместимость этих конкретных функций с её блоком не установлена и не выводится из сходства имён.

Пункт Bowers & Wilkins не вошёл в первую десятку этой машины: в её исходном FA указана система HiFi `676`, а требуемая для эффекта Harman Kardon `688` отсутствует. Это решение можно пересмотреть только после проверки реальной аудиоконфигурации.

## Поведение v0.1.4

1. Открытие плитки показывает статус записи, диагностическую кнопку и первые пять функций.
2. Следующая/предыдущая страница даёт доступ ко всем десяти без длинного набора переключателей.
3. Карточка показывает ECU, назначение, условие и ограничение. Ответ диагностического адреса помечается именно как ответ, не как поддержка кодировки.
4. Сканирование отправляет один фиксированный `UDS 22 F1 50` к функциональному адресу `0xDF` через `InternalTasu`; ответ фильтруется по SID/DID и ограничивается таймаутом. Код не предоставляет общего метода UDS и повторно проверяет allowlist перед native SOME/IP.
5. Отсутствие транспорта, отказ TASU, таймаут или пустой ответ показываются явно. Ни одна ошибка не приводит к записи.
6. Диагностика возвращает стабильный код ошибки и отдельную техническую причину. Интерфейс показывает русское сообщение по коду; неизвестная причина заменяется нейтральным русским сообщением. Технический текст остаётся только в журнале.
7. Приложение не проверяет скорость и стоянку самостоятельно; предупреждение видно на экране. `Speedlockable` — декларация для HMI, её работа на целевой MGU ещё не подтверждена.

## Требования для включения записи

Каждая функция получает независимый профиль совместимости. До её активации необходимо:

1. На **этой X3** прочитать актуальные FA, SVT, I-Level, NCD/CAFD всех затрагиваемых ECU и проверить возможность восстановления копии. Сохранить контрольные суммы и связь копии с конкретным ECU/версией без публикации VIN.
2. Подтвердить, что MGU действительно может выполнить полный цикл записи для данного ECU через доступный транспорт: сессия, аутентификация, получение исходных данных, изменение только выбранного параметра, подпись/контроль, запись, reset и повторное чтение. Один положительный ответ на `22 F1 50` для этого недостаточен.
3. Получить корректное, лицензированное и проверяемое отображение параметра в CAFD для точной версии блока. Не переносить «магические» смещения из чужой машины и не использовать зашифрованные данные BimmerCode.
4. На неподвижной машине с двигателем выключенным и стабильным питанием проверить dry run, затем один обратимый пункт на отдельном ECU. Перед каждой записью автоматически сохранять оригинал, сверять хеш и текущую версию, выполнять контролируемый процесс с контрольными точками, читать результат и предлагать восстановление только из этой копии. Обрыв связи может оставить ECU в промежуточном состоянии.
5. Для каждого пункта иметь тест успешного изменения, отмены, сбоя связи, повторной попытки без двойной записи, отказа несовместимого I-Level и восстановления. На неизвестном CAFD или неполной копии запись не предлагается.

## Дизайн и эргономика

Штатный RHMI-список рассчитан на касание и контроллер iDrive; это ещё нужно проверить на MGU. Пять функций на страницу, короткие названия и обозначение ECU в строке, подробности по нажатию. Статус «запись пока недоступна» виден до выбора пункта. Диагностическая кнопка помечена как действие на стоянке и объявлена speedlockable для штатного HMI. Внизу экрана явно сказано: «Только на стоянке; скорость приложением не проверяется». Иконка использует собственный мотив трёх блоков ECU; интерфейс наследует штатную тему ID7.

## Критерии приёмки

Для 0.1.4: исходный Store-пакет, относительный USB-каталог `catalog.json` и публикуемый `catalog.github.json` воспроизводимо собираются на ПК. Загрузчик публикует `catalog.github.json` без изменения байтов под именем `catalog.json`. SHA-256 совпадает с каталогом; в манифесте заявлен только необходимый диагностический метод TASU. Тесты проверяют фиксированный read-only запрос, русские ошибки и отсутствие технических строк в UI. Запуск на автомобиле, блокировка HMI, генерация SOME/IP config и ответы ECU пока не проверялись.

Для версии с кодированием: все пять условий предыдущего раздела должны быть пройдены на этой X3; каждая из десяти функций получает отдельный протокол проверки и подтверждённое восстановление. Завершение записи определяется повторным чтением значения, а не только ответом transport `NO_ERROR`.
