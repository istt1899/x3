Версия 0.2.0 заменяет производственную оболочку запуска и упаковку на App Kit, который используется рабочими VK/RUTUBE на X3. Прежний OnlineApp subclass, ожидание события initialized и donor runner больше не используются. Пакет содержит обычный javascript/app.js и неизменённый kit/runtime; SDK генерирует MGU Store из штатного donor на устройстве. ID и UUID плитки сохранены.

Добавлены проверки настоящего распакованного kit/runtime под Node 8 с контрактной заглушкой SDK без initialized event, реальной подготовки module package, двух страниц/DETAIL/Back, read-only диагностики и воспроизводимости. ТЗ и отчёт совета находятся в mgu-coder/REBUILD-SPEC.md и mgu-coder/COUNCIL-AUDIT-0.2.0.md.

Каталог десяти функций и чтение ECU; запись кодировок не реализована. Установка, открытие и чтение на реальной MGU в этой проверке не выполнялись. После обновления отдельно проверить плитку → MAIN → карточку → DETAIL → Назад. Источник Store: istt1899/x3, GitHub Releases. Общий каталог сохраняет видеоприложения.
