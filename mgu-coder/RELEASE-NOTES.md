Версия 0.1.3 переименовывает приложение в Bimmer Code. Идентификатор пакета сохранён, поэтому это обновление уже установленного приложения. Ошибки записи компонентов UI теперь перехватываются, включая синхронные исключения SDK, и не прерывают регистрацию плитки. Добавлена поддержка Enabled через свойство для компонентов без setEnabled и тест фоновой регистрации при ошибке отрисовки.

Пакет содержит каталог десяти функций и ограниченную диагностику только на чтение. Запись кодировок не реализована. Установка, запуск и ответы ECU на целевой X3 пока не проверены.

Закрытие приложения отменяет ещё не отправленные запросы в native-очереди. Публикация проверяет чистоту Git, совпадение артефактов с коммитом и SHA версионного тега.

Источник MGU Store: istt1899/x3, GitHub Releases. В Store выберите Settings → Check now, дождитесь версии 0.1.3 и обновите её. Фотографии подтверждают установку 0.1.2, но отсутствие плитки после перезапуска. Точная причина на устройстве ещё не установлена: для подтверждения нужны журналы запуска.
