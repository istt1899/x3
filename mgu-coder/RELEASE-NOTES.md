Версия 0.1.4 исправляет конфигурацию загрузки экрана и плитки по образцу работающих VK/RUTUBE. config/base.json теперь явно включает rhmiLoadingEnabled и entryPointLoadingEnabled; раньше он был пустым, и SDK с выключенными loader defaults не создавал RHMI и entry points. Также применены рабочие параметры insertionStateId=20974, private=false и defaultLanguage=en_GB. ID пакета и UUID сохранены.

Пакет содержит каталог десяти функций и ограниченную диагностику только на чтение. Запись кодировок не реализована. Установка, запуск и ответы ECU на целевой X3 пока не проверены.

Закрытие приложения отменяет ещё не отправленные запросы в native-очереди. Публикация проверяет чистоту Git, совпадение артефактов с коммитом и SHA версионного тега.

Источник MGU Store: istt1899/x3, GitHub Releases. В Store выберите Settings → Check now, дождитесь версии 0.1.4 и обновите её. Тесты проверяют запуск с выключенными defaults SDK и сохранение флагов в реально связанном пакете. Появление плитки на целевой MGU ещё требует проверки владельца.
