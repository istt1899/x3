# Исправления по аудиту 0.1.0 → 0.1.1

| Пункт | Решение |
|---|---|
| P1-01 | Оставлен открытым: добавление новых отметок авторства исключено по указанию владельца. Существующие лицензии и уведомления сохранены. |
| P2-01 | `npm run build` создаёт отдельный `catalog.github.json` для GitHub и относительный `catalog.json` для USB. `tools/catalog.js` воспроизводит преобразование без сети; `tools/publish-github.js` публикует готовые байты без переписывания URL. |
| P2-02 | Стабильные коды ошибок отделены от технического текста; UI показывает русские сообщения и нейтральный текст при неизвестном коде. Сырая причина доступна только журналу. |
| P2-03 | Принят предложенный аудитором вариант явного ограничения заявления: приложение не проверяет скорость/стоянку самостоятельно. Это указано в UI, README и ТЗ. `Speedlockable` сохранён как декларация HMI; его работа требует проверки на MGU. |

Сигнал скорости нельзя считать проверенным только по наличию похожего интерфейса в чужом проекте. Новые интерфейсы автомобиля и диагностические запросы не добавлены. Для независимой проверки стоянки в будущем потребуются доступный на этой X3 provider, свежее корректное значение и блокировка действия при отсутствии данных.

Новая версия получает отдельный архив и тег `marku_x3_coding@0.1.1`. Архив и версионный тег 0.1.0 сохраняются. Релиз `catalog` служит обновляемым указателем на текущий пакет.

Дополнительно исправлена отмена: закрытие приложения блокирует ещё не отправленный запрос, в том числе внутри отложенной native-очереди. Загрузчик релиза требует чистый Git, сверяет байты архивов с коммитом и проверяет SHA версионного тега; несовпадение прерывает публикацию.

При замене каталога проверка скачивает файл с идентификатором GitHub asset в query-параметре: устаревший кеш редиректа не должен возвращать удалённый каталог и запускать повторную замену. Публикуемые байты каталога при этом не меняются.

Средства сборки и публикации требуют Node.js 18+. Прикладные тесты диагностики и UI дополнительно проверяются на Node 8. Реальная установка, RHMI, native SOME/IP и чтение ECU на автомобиле не проверены. Запись кодировок не реализована.
