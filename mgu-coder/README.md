# Кодировки • X3

Приложение для BMW X3 G01 с MGU / iDrive 7 и уже установленным MGU Store. Версия 0.1.0 — устанавливаемый **каталог 10 функций и диагностика ECU только на чтение**. Приложение не меняет кодировки и не содержит кнопки записи. Этот статус явно указан в меню и каталоге Store.

## Что работает

- Штатная плитка и меню RHMI на экране iDrive 7, с управлением касанием и контроллером iDrive.
- Две страницы по пять функций. Каждая карточка показывает назначение, нужный ECU и условия доступности.
- По нажатию «Проверить блоки на стоянке» выполняется **один** запрос `UDS 22 F1 50` через штатный MGU SOME/IP `InternalTasu`. Ответы показываются как диагностические адреса. Ответ ECU не означает, что конкретная кодировка поддерживается или прочитана.
- Никакого автоматического сканирования при запуске, VIN-запросов, сохранения персональных данных, записи/сброса ECU или изменения настроек автомобиля.

Целевая машина выбрана по сообщению владельца: X3 с MGU Store. В локальном исходном архиве машины есть FA, SVT и 34 NCD; SVT содержит HU_MGU, BDC_BODY3, ACSM5, DME_BAC2, DKOMBI4 и RAM. **Актуальный I-Level и текущие NCD после восстановления не подтверждены.** Эти файлы не входят в пакет.

## Сборка

На компьютере с Node.js 18+:

```powershell
cd mgu-coder
npm run build
npm test
```

Готовый USB-каталог: [`../output/x3-coding-usb`](../output/x3-coding-usb). Скопируйте содержимое этой папки в корень USB-накопителя. В автомобиле откройте **MGU Store → USB → Кодировки • X3**. Нужны уже работающий Store, `mgu-deploy` 0.7.11 или новее и совместимый SDK donor на этой MGU. Сборка исходного OAP-приложения происходит на головном устройстве; компьютерный `npm run build` не доказывает успешную установку на автомобиле.

Перед запуском диагностики автомобиль должен стоять, двигатель выключен, включено зажигание/диагностический режим и обеспечено стабильное питание. При отсутствии `InternalTasu` или права на него меню покажет ошибку и не отправит запрос. Сканирование не подтверждает, что можно кодировать найденные блоки.

Удаление: **MGU Store → Installed → Кодировки • X3 → Uninstall**.
