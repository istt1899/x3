# Совет: глубокий аудит отказа открытия

Проверены отдельно lifecycle/RHMI, упаковка Store и достоверность тестов. Основания: фотографии владельца, исходники 0.1.5, рабочий App Kit VK/RUTUBE из этого же репозитория. Журнал процесса и штатный SDK конкретной MGU не доступны, поэтому точное исключение на машине не установлено.

## Находки

- **P0, зависимость от неподтверждённого события:** `apps/marku_x3_coding/src/coding_app.js` держал setup/initialized/open в обработчике `initialized`. Рабочий `media/core/kit/runtime/mgu.js` сам ждёт app.start и затем вызывает app.initialized. Если ожидаемое событие не возникает в этом SDK, первый код вообще не выполняет открытие. Это подтверждённое расхождение контрактов; причинность на конкретной машине остаётся выводом из симптомов, не runtime-трассой.
- **P1, ложная полнота startup-теста:** прежний тест напрямую вызывал app.appInitialized, обходя обработчик события. Fake OnlineApp выдавал любой запрошенный RHMI component и не проверял настоящий loader/start contract. Успех такого теста не подтверждал открытие поставляемого пакета.
- **P1, другой путь установки:** 0.1.5 — source bundle с mgu-app.json и donor runner. Рабочие VK/RUTUBE — module-mode npm package с прямым javascript/app.js и kit/runtime. Порт устраняет комбинацию двух непроверенных механизмов запуска.
- **P2, ручная схема RHMI:** типы компонентов, focus и ресурсы задавались отдельно от рабочего generator. В 0.2.0 схема генерируется тем же kit.

## Решение

Порт 0.2.0 заменяет производственную оболочку на App Kit. Диагностический allowlist и модель десяти карточек сохранены. Исходный kit/runtime не патчится ради прохождения тестов; его хеши фиксируются в build-evidence.json. Новый тест пакета реально выполняет preparePackage и проверяет flat package. Проверка lifecycle запускает реальный kit/runtime с SDK-shaped stub без выдуманного initialized event. Тесты callback UI остаются отдельным уровнем проверки.

ТЗ: [REBUILD-SPEC.md](REBUILD-SPEC.md). Приёмка на реальной MGU остаётся обязательным отдельным шагом; установка и тест на ПК не называются доказанным открытием на машине.
