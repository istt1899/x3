# Источник обновлений MGU Store

Явное указание владельца от 09.11.2026: все дальнейшие публикации его приложений и обновлений делать **только в `istt1899/x3`**, общий релиз `catalog` и корневой `catalog.json` этого репозитория.

- Уже добавленный в машине источник — `istt1899/x3`, тип GitHub Releases. Не предлагать другую ссылку и не считать отдельный `bmw-kaluga-cameras` источником автомобиля.
- При обновлении Waze Стрелка сохранять остальные компоненты общего каталога, их версии, зависимости, адреса и хэши.
- `istt1899/bmw-kaluga-cameras` — прежнее происхождение исходников и архивов, не место новых публикаций. Не запускать его publisher и не обновлять там release/catalog/main.
- Сначала подготовить и проверить оба пакета, затем опубликовать их в `x3`, и только последним шагом переключать общий каталог. Проверять настоящий reader/fetch MGU Updater по источнику `istt1899/x3`.
- Происхождение и старые встроенные адреса данных не равны источнику Store. Если требуется перенос такого runtime-адреса, выполнять его отдельно с проверкой совместимости; не объявлять перенос выполненным только по замене каталога.
